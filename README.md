### 🧠 Engineering Philosophy & Expertise

I am a Full-Stack Software Engineer specializing in the intersection of **scalable web architectures** and **Artificial Intelligence**. I don't just build websites; I design distributed systems, integrate autonomous AI workflows, and engineer high-performance APIs capable of handling complex, real-world data at scale.

*   **🤖 AI & Machine Learning:** Designing agentic workflows, integrating Large Language Models (LLMs), and building intelligent microservices that automate complex business logic.
*   **⚡ Scalable Architecture:** Architecting cloud-native backends utilizing Edge Functions, serverless databases, and robust RPC APIs to ensure sub-second latency globally.
*   **🌐 Modern Frontend:** Crafting pixel-perfect, highly reactive, and accessible user interfaces using bleeding-edge framework ecosystems.
*   **🔒 Security & DevOps:** Implementing strict RLS (Row Level Security), secure authentication pipelines, and automated CI/CD deployments.
